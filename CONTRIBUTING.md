# Contributing

Use Node.js 22.12 or newer. Run `npm ci`, `npm test`, and `npm run build` before submitting a pull request. Describe the changed behavior and relevant checks.

Keep the README section order aligned with the referenced Colosseum example. Distinguish shipped functionality, tested behavior and future work. Do not add token-price, revenue or traction claims without evidence.

Do not commit credentials, wallet secrets, player data, local dependency folders or build output. CloudCode and live title changes require separate platform deployment; changing files here does not publish them automatically.

See NOTICE.md for the source attribution limitations.
